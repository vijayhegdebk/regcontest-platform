# RegContest Platform

Configurable Runtime Governance Platform for Agentic Banking Decisions

**Contestability-by-Construction** for Loans, Credit Cards, Fraud, KYC and more.

## Features
- Configurable via YAML meta files
- By-construction Contestability Artifacts
- Runtime policy enforcement
- Model drift monitoring
- Deterministic re-decisioning

## Quick Start
```bash
streamlit run web_interface/app.py
```
